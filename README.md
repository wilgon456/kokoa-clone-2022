## Included screens

Login, friends, chats, an individual chat, discovery, more and settings. The project focuses on mobile layouts and shared UI components.

## Preview locally

```bash
git clone https://github.com/wilgon456/kokoa-clone-2022.git
cd kokoa-clone-2022
python3 -m http.server 8000
```

Open **http://localhost:8000/Index.html** — the capital **I** matters on case-sensitive servers. Use a narrow browser window or mobile device emulation; the page intentionally shows a “Your screen is too big” overlay on wide screens.
