## 포함된 화면

로그인, 친구, 채팅 목록, 개별 채팅, 찾기, 더보기, 설정 화면입니다. 모바일 배치와 공통 UI 구성을 익히는 데 초점을 맞췄습니다.

## 로컬 미리보기

```bash
git clone https://github.com/wilgon456/kokoa-clone-2022.git
cd kokoa-clone-2022
python3 -m http.server 8000
```

**http://localhost:8000/Index.html**을 엽니다. 대소문자를 구분하는 서버에서는 대문자 **I**가 중요합니다. 브라우저 폭을 줄이거나 모바일 기기 모드를 사용하세요. 넓은 화면에는 의도적으로 “Your screen is too big” 안내가 표시됩니다.

## 페이지 안내

| 페이지 | 화면 |
| --- | --- |
| `Index.html` | 로그인 |
| `friends.html` | 친구 |
| `chats.html` / `chat.html` | 채팅 목록 / 대화 |
| `find.html` | 찾기 |
| `more.html` / `setting.html` | 더보기 / 설정 |

화면을 따라 만든 학습 프로젝트입니다. 실제 계정·메시지 전송·백엔드는 없으며 카카오의 공식 서비스가 아닙니다.
